# Feedback and contributions

**English** | [简体中文](CONTRIBUTING.zh-CN.md)

English and Chinese reports and suggestions are welcome in [Issues](https://github.com/randymu/unplugcue/issues). This is a spare-time project; prompt replies and implementation of every request are not guaranteed.

Include app/macOS versions, chip, drive/enclosure/interface, filesystem, reproduction steps, and actual errors. Redact UUIDs, serial numbers, private paths, and sensitive filenames. Do not upload an unreviewed full diagnostic export.

For code changes, describe the problem first. Changes to drive discovery or unmounting should document meaningful mock verification and actual-device test coverage. Never force-unplug a working drive for a test. Do not introduce forced unmounts or destructive actions without user confirmation.

Contributors must have the right to share their submissions and agree to provide them under this repository's existing LICENSE. Do not submit incompatible third-party code or assets. An issue discussion before a change is welcome.
