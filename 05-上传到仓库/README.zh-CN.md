# UnplugCue

[English](README.md) | **简体中文**

<img src="Resources/AppIcon-1024.png" width="112" alt="UnplugCue 应用图标">

外置硬盘卸载前查占用，卸载后提醒拔线或关电。原名 LaCie Safe Off，不限硬盘品牌。

**[下载 2.1.1 测试版](https://github.com/randymu/unplugcue/releases/tag/v2.1.1)** · [更新记录](CHANGELOG.zh-CN.md) · [反馈问题](https://github.com/randymu/unplugcue/issues)

macOS 14+，Apple Silicon / Intel 通用包，无需 Xcode。Intel 仅交叉编译，未真机测试；并未逐一验证所有 macOS 版本。

**界面语言：目前应用界面主要为简体中文；本项目文档提供中英文，尚未完成英文界面适配。**

当前为测试发布（Pre-release）。已完成模拟测试与打包验证，尚未验证所有实际设备和系统组合。

## 功能

- 自动发现 USB / Thunderbolt 等外置物理 HDD 和 SSD。
- 查看打开文件的应用和进程，帮助排查卸载失败。
- 确认后正常卸载整块物理盘上的所有卷，不强制卸载、不终止占用应用。
- SSD 默认立即提醒，HDD/未知类型默认等待 60 秒，可按盘设置。

60 秒只是提醒缓冲，不检测机械盘停转。本工具不控制硬盘电源。

## 安装

在 Releases 的 Assets 下载 macOS universal ZIP，解压后把应用拖入“应用程序”。Source code 是源码，不是安装包。

本版仅本地临时签名，未完成 Apple 开发者身份签名及公证。首次打开可能被系统拦截。确认来源可信后，可到系统设置“隐私与安全性”查看该应用的提示，不要关闭全局安全保护。若提示损坏或恶意软件，先停止并反馈，不要盲目绕过。

通知权限可选；拒绝后可在窗口查看状态。正常使用不要求管理员密码、完全磁盘访问或辅助功能权限。

## 使用

先保存工作并等待复制、备份结束 → 选择硬盘 → 检查占用（可选） → 安全卸载整盘并确认 → 等待本次操作完成及提醒。

整盘操作包含该物理盘上的所有卷。操作期间不要拔插、换盘或重新挂载。重新挂载后须重新卸载，不能凭旧通知关电。使用后可退出，无需常驻。

## 范围与限制

排除内置盘、磁盘映像、网络卷；禁止卸载当前系统所在外置盘。不支持跨多个物理存储的 APFS 容器及 Apple 软件 RAID；信息不完整时停止。

占用列表可能受权限限制而不完整，打开文件也不一定阻止卸载，最终由 macOS 决定。卸载超时意味着结果不确定，请等待并在磁盘工具确认，勿立即重复提交或断电。
