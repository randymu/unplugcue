UnplugCue 2.1.1 (build 9)
更名测试版 | 2026-11-05

界面语言：目前主要为简体中文，尚未完成英文界面适配。

系统要求
macOS 14 或更新版本。通用二进制，包含 Apple Silicon 与 Intel 架构。
本次在 Apple Silicon 上完成编译及模拟测试；Intel 仅交叉编译，未在 Intel 真机测试。
不需要安装 Xcode、命令行工具或额外依赖。

安装和启动
1. 解压后，把 UnplugCue.app 拖到你自己的“应用程序”文件夹。
2. 打开应用。可在主窗口操作，也可从顶部菜单栏图标重新打开主窗口。
3. 首次需要通知权限时，可以允许；拒绝通知不影响正常卸载和窗口内状态显示。
4. 本版仅使用本地临时签名，未通过 Apple 开发者签名及公证。首次打开可能被 Gatekeeper 拦截。
   这不代表 macOS 已确认它恶意，也不代表它通过 Apple 安全审查。
   只有确认来源可信后，才由你自己决定是否在系统设置“隐私与安全性”中允许这一个应用。
   不要关闭 Gatekeeper、SIP 或其他全局安全保护，不需要安装配置描述文件。
   若提示“已损坏”或“包含恶意软件”，先停止操作并让分享者核对原始包，不要盲目绕过。

使用
无需绑定分享者的硬盘，会自动发现当前 Mac 上的外置物理 HDD 和 SSD。
支持的不局限于 LaCie 品牌。网络盘、磁盘映像、内置盘不在操作范围内。
选择硬盘后，“检查占用”只读取打开文件的进程，不会卸载或结束应用。
“安全卸载整盘”会在确认后正常卸载同一物理磁盘上的所有卷，不是只卸载一个分区。
卸载失败后显示系统错误并复查占用者，不强制卸载、不终止占用应用。
SSD 默认直接提醒可拔线；机械盘和类型未知的盘默认等待 60 秒。
60 秒只是提醒缓冲，软件不能检测机械盘是否停转。
操作完成后可从主窗口或菜单栏点击“退出”，不必常驻。

安全边界（请务必阅读）
不格式化磁盘、不删除硬盘文件、不修复文件系统、不检测坏道或寿命。
没有自动联网、遥测、账号登录、自动更新、后台安装器、登录项或管理员辅助进程。
正常使用不要求管理员密码，也不要求授予“完全磁盘访问”或“辅助功能”。
占用检查受 macOS 权限限制，不保证列出所有系统/其他用户进程；空列表不等于绝对无人占用。
系统服务和打开文件的进程不一定阻止卸载，最终以 macOS 正常卸载结果为准。
不支持跨多个物理存储的 APFS 容器及 Apple 软件 RAID，信息不完整时停止操作。
正常工作的硬件 RAID 盒若对系统呈现为单一物理设备，软件只看得到该逻辑设备。
请先保存工作并等待复制、备份、照片导入等写入任务结束，再进行卸载。
卸载和倒计时期间不要插拔、更换硬盘、休眠 Mac 或重新挂载目标卷。
工具会核对 UUID、本次连接的 IOMedia 身份和物理分区指纹，但核对与 diskutil 执行之间仍有很短的非原子窗口。
因此不能保证在用户强行热拔插、更换设备或硬件异常时完全避免设备变化竞态。
命令超时表示结果不确定，不等于成功或取消；本次运行会暂停继续提交卸载命令。
出现超时请等待并在磁盘工具确认状态；不要马上反复重试、退出重开或直接断电。
已卸载的绿色状态会随事件更新，空闲时约每 15 秒复查；另一块盘正在操作时复查会延后。
15 秒不是最大延迟保证，绿色状态不是持续的硬件电源许可。
若重新挂载，必须重新完成卸载；不要凭旧通知关电。
请保留重要数据的独立备份。代码审查与模拟测试不构成零漏洞、零丢失风险的保证。
朋友首次使用应先用已备份、非关键的移动盘验证兼容性。

本地数据与隐私
分享包不包含分享者的硬盘 UUID、文件路径、偏好设置、设备诊断或会话记录。
应用使用后仅在以下位置保存各硬盘的提醒偏好：
~/Library/Application Support/LaCieSafeOff/preferences.json
旧版本可能还保存 target.json 和 target-8t.json；本分享包不携带这些文件。
不自动创建持久诊断日志。手动导出诊断会包含设备名、UUID 和挂载路径，分享前请审阅。

完整移除
1. 从应用菜单栏或主窗口点击“退出”。
2. 将安装的 UnplugCue.app 移到废纸篓。
3. Finder 中按 Command+Shift+G，前往：
   ~/Library/Application Support/
   将其中 LaCieSafeOff 文件夹移到废纸篓（如果存在）。
4. Finder 中前往 ~/Library/Preferences/，将
   com.randymu.LaCieSafeOff.plist 移到废纸篓（如果存在）。
5. 可在系统设置“通知”中关闭本应用通知，并删除自己手动导出的诊断文件。
没有需要卸载的驱动、后台服务或登录项。macOS 自己维护的通知权限、启动记录或系统日志可能保留。
未确认不再需要前，不必清空废纸篓。
